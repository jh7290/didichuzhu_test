# 项目面试介绍稿

## 一句话介绍

我做了一个基于 Python + Pytest + Requests 的网约车订单接口自动化测试项目，使用本地 mock 服务模拟登录、创建订单、查询订单、取消订单等核心接口。

## 项目背景

这个项目是为了模拟网约车业务质量保障场景，重点覆盖登录鉴权、订单创建、订单查询、订单取消和异常参数校验。

## 我做了什么

1. 设计登录和订单接口测试用例。
2. 使用 Python 的 http.server 写了一个本地 mock 服务。
3. 使用 requests 封装 GET / POST 请求。
4. 使用 pytest 组织测试用例。
5. 使用参数化覆盖多组登录和订单异常场景。
6. 使用 fixture 统一获取 token 和构造 headers。
7. 使用 JSON 文件管理测试数据。
8. 对状态码、响应字段、错误提示和订单状态进行断言。

## 面试讲法

我主要从正常流程、异常参数、鉴权失败和状态流转几个角度设计用例。比如登录接口覆盖手机号为空、格式错误、账号不存在、密码错误；订单接口覆盖未登录、起点为空、终点为空、附近无司机、重复取消等场景。

在代码实现上，我把请求方法封装到 common/request_util.py，把公共断言放到 common/assertions.py，测试数据放在 data 目录，并通过 pytest fixture 获取 token 和 headers。这样测试用例更清晰，也方便后续扩展。

## 项目收获

这个项目让我理解了测试开发不只是写脚本，还要先知道测什么，再通过自动化方式提升回归效率。
