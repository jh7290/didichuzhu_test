# 测试用例文档

## 登录接口

| 编号 | 场景 | 测试数据 | 预期结果 |
|---|---|---|---|
| LOGIN_001 | 正确手机号和正确密码登录 | phone=13800138000, password=123456 | 登录成功，返回 token |
| LOGIN_002 | 手机号为空 | phone="", password=123456 | 返回 400，提示手机号不能为空 |

| LOGIN_007 | 账号不存在 | phone=13999999999 | 返回 404，提示账号不存在 |
| LOGIN_008 | 密码错误 | password=111111 | 返回 401，提示密码错误 |

## 创建订单接口

| 编号 | 场景 | 测试数据 | 预期结果 |
|---|---|---|---|
| ORDER_001 | 正常创建订单 | 起点=学校，终点=火车站，司机数=3，金额=28.5 | 返回 201，订单状态 created |
| ORDER_002 | 未登录创建订单 | 不带 token | 返回 401，提示未登录或认证失败 |
| ORDER_003 | 起点为空 | start_place="" | 返回 400，提示起点和终点不能为空 |
| ORDER_004 | 终点为空 | end_place="" | 返回 400，提示起点和终点不能为空 |
| ORDER_005 | 起终点相同 | 学校 -> 学校 | 返回 400，提示起点和终点不能相同 |
| ORDER_006 | 附近无司机 | driver_count=0 | 返回 409，提示暂无司机 |
| ORDER_007 | 金额无效 | price=0 | 返回 400，提示金额无效 |
