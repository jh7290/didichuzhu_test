# 项目查看顺序

你第一次打开这个项目时，建议按下面顺序看。

## 1. 先看 README.md

README 是项目说明，里面有：

1. 项目背景
2. 技术栈
3. 项目结构
4. 如何运行
5. 简历项目描述

## 2. 看 server/mock_server.py

这是本地模拟接口服务，模拟了这些接口：

1. GET /health
2. POST /login
3. POST /orders
4. GET /orders/{order_id}
5. POST /orders/{order_id}/cancel

它相当于一个假的后端，方便你练接口自动化。

## 3. 看 common/request_util.py

这里封装了 requests：

```python
api.get(...)
api.post(...)
```

这样测试用例里不用每次写完整 requests.get / requests.post。

## 4. 看 tests/conftest.py

这里是 pytest fixture：

1. api：请求工具
2. login_cases：读取登录测试数据
3. order_cases：读取订单测试数据
4. token：登录并获取 token
5. auth_headers：构造带 token 的 headers
6. created_order：创建一个订单，供查询/取消测试使用

## 5. 看 tests/test_login.py

这里是登录接口测试，包括：

1. 登录成功
2. 手机号为空
3. 手机号格式错误
4. 密码为空
5. 账号不存在
6. 密码错误

## 6. 看 tests/test_order.py

这里是订单接口测试，包括：

1. 创建订单成功
2. 未登录创建订单
3. 起点为空
4. 终点为空
5. 起终点相同
6. 附近无司机
7. 金额无效
8. 查询订单
9. 取消订单
10. 重复取消订单

## 7. 看 docs/interview_project_intro.md

这是面试时讲项目的材料，可以直接背。

## 8. 运行项目

现在可以直接运行测试，pytest 会自动启动 mock 服务：

```bash
python -m pytest -v
```

我已经帮你运行过：

```text

```

说明项目可以正常运行。
